# Айсана — голосовой робот на Jetson Nano

Айсана слышит (микрофон KT USB Audio), говорит (колонка Xiaomi, в ALSA — «USB Composite Device»), видит (камера CSI на Jetson) и управляет двумя руками Arm team (Arduino Mega по USB). Понимает русский, казахский, английский и египетский арабский.

## Два режима

| | `aisana_realtime.py` — **быстрый, рекомендуемый** | `robot.py` — классический |
|---|---|---|
| Как работает | Звук идёт в OpenAI Realtime и обратно потоком | Запись → распознавание → GPT → озвучка |
| Задержка | Низкая: ответ звучит потоком, отдельных запросов STT/GPT/TTS нет | До шести запросов к OpenAI подряд на реплику |
| Имя «Айсана» | Нужно, чтобы начать разговор; дальше 20 с без имени | Нужно, чтобы начать разговор; дальше 35 с без имени |
| Камера, руки, погода, поиск | Модель сама вызывает инструменты | Команды рукам разбираются локально, остальное через маршрутизацию |
| Память диалогов SQLite | Пока нет | Есть |

## Запуск на Jetson

Быстрый режим работает в `.venv` (там websocket-client), классический — в системном `python3` (там cv2 из JetPack). У системного `python3` на Jetson нет pip.

```bash
cd ~/ai_robot
git pull --ff-only origin main
# один раз:
.venv/bin/python -m pip install "pyserial==3.5" "websocket-client==1.3.1"
sudo apt install python3-serial                       # pyserial для robot.py
sudo usermod -aG dialout $USER                        # доступ к Arduino; затем выйти из SSH и зайти снова
# каждый раз:
.venv/bin/python -m unittest discover -s tests -v     # офлайн-тесты, без железа
.venv/bin/python -u aisana_realtime.py 2>&1 | tee realtime.log   # быстрый режим
# или
python3 -u robot.py 2>&1 | tee robot.log              # классический режим
```

`OPENAI_API_KEY` должен быть в окружении. Флаг `-u` нужен, чтобы лог сразу писался в файл. Камеру realtime-режим снимает через `/usr/bin/python3 camera.py`, поэтому cv2 в `.venv` не нужен.

## Руки Arm team (Arduino Mega по USB)

Подключите USB-кабель Arduino Mega к Jetson. Прошивку Arm team (`robotic_arms_*.ino`) **менять не нужно**: Айсана отправляет ей те же текстовые команды, что и Serial Monitor (115200 бод, перевод строки).

- Порт находится сам (обычно `/dev/ttyACM0`). Если плат несколько, Айсана откажется угадывать: задайте `AISANA_ARM_PORT=/dev/ttyACM0`.
- Без Arduino робот работает как обычно и пишет `Arm: not connected`.
- Отправляются **только** команды из белого списка: позиции 0–4 (вся рука, плечо или локоть), открыть/закрыть захват, стоп (`x`), статус (`p`). Произвольный текст на Arduino не попадает никогда.
- **«Айсана, стоп»** в обоих режимах сразу отправляет аварийную остановку `x`.

### Что можно сказать Айсане

Разговор начинается с имени: «Айсана, …». После её ответа 20 секунд можно говорить без имени.

| Что сказать | Что произойдёт |
|---|---|
| «Айсана, руки в позицию 2», «правую руку во вторую позицию», «левая рука, позиция четыре» | Рука (плечо и локоть) едет в сохранённую позицию 0–4 |
| «Айсана, правое плечо в позицию 1», «левый локоть в позицию 3» | Только этот сустав в позицию |
| «Айсана, руки в исходное положение», «руки в ноль» | Позиция 0 |
| «Айсана, рука чуть-чуть наверх» | Плечо выше на 5° |
| «подними правую руку немного», «левую руку немного ниже» | На 10° |
| «подними левую руку», «опусти руки» | На 15° |
| «подними руку сильно» | На 30° |
| «правую руку выше на 20 градусов» | На столько градусов, максимум 45 за раз |
| «левый локоть чуть выше», «согни/опусти правый локоть немного» | То же, но локтем |
| «ещё», «ещё чуть-чуть» (только в быстром режиме) | Повторить последнее движение |
| «Айсана, открой правую руку», «открой захваты» | Открыть захват |
| «Айсана, закрой левую руку», «сожми захват», «возьми» | Закрыть захват |
| **«Айсана, стоп»**, «останови руки» | Аварийная остановка всего (`x`) |
| «Айсана, где сейчас руки?», «статус рук» (быстрый режим) | Позиции суставов |
| «Aisana, move the left arm to position 3», «right arm a bit higher», «close both grippers», «stop the arms» | То же по-английски (казахский и арабский тоже понимает) |

«Наверх» — это в сторону позиции 4, как кнопка «forward» у Arm team. Если руки поедут не туда, запускайте с `AISANA_ARM_UP=position0`. Выход за пределы суставов прошивка не допускает: рука остановится на ближайшем пределе.

Без рук Айсана тоже умеет: «что ты видишь?», «прочитай, что здесь написано», «какая погода в Астане / завтра?», «кто победил на выборах?» (поиск в интернете), обычные вопросы. «Айсана, отбой» закрывает разговор; после этого снова нужно имя.

Важно для Arm team:
- При открытии USB-порта Arduino Mega перезагружается — это ожидаемо. Прошивка рассчитана на старт: локти стартуют из сохранённой калибровки, шаговики держат позицию. Айсана ждёт строку `Both arms ready.` и только потом шлёт команды. Моторное питание включайте **до** запуска Айсаны.
- Сервопривод левого локтя висит на пине 13 — это же светодиод платы, который загрузчик мигает при перезагрузке. Если локоть дёргается при запуске Айсаны, перенесите его на свободный пин (например, 11) и поменяйте `L_SERVO_PIN`.
- Пока Айсана держит порт, Serial Monitor в Arduino IDE этот порт открыть не сможет.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `AISANA_ARM` | `1` | `0` — не подключаться к Arduino |
| `AISANA_ARM_PORT` | автопоиск | Явный порт Arduino |
| `AISANA_ARM_ECHO` | `1` | Вывод Arduino в консоль: `1` — только ошибки и предупреждения, `2` — всё, `0` — ничего |
| `AISANA_ARM_UP` | `position4` | `position0` — поменять местами «вверх» и «вниз» |
| `AISANA_REALTIME_WAKE` | `1` | Realtime: `0` — отвечать на любую речь (старое поведение) |
| `AISANA_DIALOG_TIMEOUT` | `20` | Realtime: секунд без имени после ответа |
| `AISANA_REALTIME_MODEL` | `gpt-realtime-2.1-mini` | Модель realtime |
| `AISANA_REALTIME_BARGE_IN` | `0` | Перебивать голосом (только с наушниками) |
| `TARZA_CAMERA_ROTATE` | `180` | Поворот кадра камеры (камера стоит вверх ногами); `0`, `90`, `270` |
| `TARZA_DIALOG_TIMEOUT` | `35` | `robot.py`: секунд без имени после ответа |
| `SADAM_WAKE_MODE` | `legacy` | `robot.py`: `vosk` — офлайн-активация, см. WAKE_WORD_SETUP.md |

Остальные настройки `robot.py` описаны в MODERNIZATION.md (часть значений по умолчанию с тех пор изменилась — верьте коду).

## Файлы

- `aisana_realtime.py` — быстрый режим: Realtime API, имя, инструменты.
- `robot.py` — классический режим.
- `aisana_arm.py` — USB-связь с Arduino рук: поиск порта, белый список команд, разбор голосовых команд.
- `sadam_features.py` — погода (Open-Meteo), веб-поиск, определение конца фразы.
- `aisana_memory.py` — память диалогов (SQLite).
- `wake_listener.py` — офлайн-активация по имени (Vosk).
- `camera.py` — один кадр с камеры в `photo.jpg`.
- `speech.py`, `tts.py`, `vision.py` — старые тестовые скрипты первых версий.

## Разработка

Код должен работать на **Python 3.6** (Jetson Nano). CI на GitHub проверяет это (vermin) и гоняет офлайн-тесты на каждый push и pull request. Пока тесты красные, на Jetson не обновляйтесь.
