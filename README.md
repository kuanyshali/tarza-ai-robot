# Айсана — голосовой робот на Jetson Nano

Айсана слышит (микрофон KT USB Audio), говорит (колонка Xiaomi, в ALSA — «USB Composite Device»), видит (камера CSI на Jetson) и управляет двумя руками Arm team (Arduino Mega по USB). Понимает русский, казахский, английский и египетский арабский.

## Быстрый запуск на Джетсоне

```bash
cd ~/ai_robot
git pull --ff-only     # обновиться
./start.sh             # запустить Айсану; если колёса не откалиброваны, сначала предложит калибровку
./stop.sh              # остановить из любого терминала (или Ctrl+C)
```

Настройки по умолчанию в `start.sh`: IP ног `http://10.42.0.148:5000`, `AISANA_ECHO_TAIL_SECONDS=0.4`, `AISANA_PLAYBACK_LEAD_MS=150`. Любую можно поменять на один запуск: `AISANA_HUMOR=70 ./start.sh`.


### Пульт с телефона

Пульт запускается сам при включении Джетсона (systemd-служба `aisana-panel`). Айсана сама не включается: нажмите «Включить» на пульте.

```bash
./install_panel_service.sh            # один раз: включить автозапуск пульта
./install_panel_service.sh --remove   # убрать автозапуск
sudo systemctl restart aisana-panel   # перезапустить пульт (Айсана не выключится)
journalctl -u aisana-panel -n 30      # лог пульта
```

Из любой точки без Tailscale на телефоне (Tailscale Funnel): **https://mmae603-desktop.tail16cc45.ts.net**. Включено один раз командой `sudo tailscale funnel --bg 8080`, держится после перезагрузки; выключить: `sudo tailscale funnel --https=443 off`.

Открыть в браузере телефона: `http://<IP Джетсона>:8080` (через Wi-Fi робота или Tailscale: `http://100.109.60.97:8080`). Кнопки: Включить/Выключить, СТОП, Помахать, Танцевать, громкость колонки Xiaomi (ползунок, 30/50/70/85/100, «Проверить звук»; запоминается и возвращается после переподключения колонки), ползунок юмора (меняется молча и запоминается до следующего раза), «Сказать это», «Спросить её», статус рук/ног/камеры/интернета и лог. Без пароля: не давайте ссылку посторонним. Сама Айсана принимает команды пульта только с этого же Джетсона (127.0.0.1:8091).

### Если камера пишет «Failed to create CameraProvider» / «(Argus) Error»

Служба камеры `nvargus-daemon` сломалась (обычно после грубого выключения Айсаны). `start.sh` теперь сам перезапускает эту службу при каждом запуске (правило sudo ставит `./install_panel_service.sh`, без пароля и только для этой команды). Вручную: `./stop.sh; sudo systemctl restart nvargus-daemon; ./start.sh`.

### Университетский Wi-Fi NU_Campus

`NU_Campus_WiFi` — WPA2-Enterprise (логин и пароль от университетской почты). Запустите на Джетсоне сами и введите логин и пароль (в git и в чат они не попадают, хранятся только в системном файле NetworkManager, доступном root):

```bash
./connect_nu_campus.sh            # роутер 4G Altel первым, NU_Campus запасным (как сейчас)
./connect_nu_campus.sh --first    # наоборот: NU_Campus первым (экономит трафик симки)
./connect_nu_campus.sh --remove   # забыть NU_Campus и пароль
```

### iPhone как микрофон

На пульте карточка «🎤 Микрофон iPhone». Работает **только по https-ссылке** (`https://mmae603-desktop.tail16cc45.ts.net`): по `http://…:8080` Safari не даёт микрофон.

- **Режим кнопки**: зажми «Зажми и говори», скажи, отпусти. Имя «Айсана» не нужно, посторонние разговоры не слышны, нажатие перебивает её ответ. Лучший режим для презентации и шумного зала.
- **Слушать всё время**: iPhone работает как обычный микрофон (нужно «Айсана, …», эхо-защита как обычно).
- Пока iPhone присылает звук, USB-микрофон молчит; через 2,5 с после закрытия страницы или блокировки экрана снова слушает USB-микрофон.
- После выключения микрофона iPhone снова слушает USB-микрофон, и к ней опять нужно обращаться «Айсана, …». На пульте в строке «Микрофон» видно уровень USB-микрофона: «тишина / тихо / слышит голос».
- Экран iPhone должен быть включён, Safari открыт на пульте. Лучше на зарядке. Проверять на iPhone X; iPhone 6 (iOS 12) может заработать, но микрофон в старом Safari ненадёжен.
- Звук: 24 кГц, моно, примерно 50 КБ/с, только пока микрофон включён.

### Колёса автоматически

Приложение ног на Pi выключает моторы через 0,75 с без сигнала «я на связи» (его шлёт страница `/control`, пока она открыта). Айсана теперь сама шлёт этот сигнал каждые 0,15 с, пока моторы включены, поэтому страница на Pi не нужна. Если моторы выключились, она снова включает их без калибровки, а если ODrive нужна калибровка, калибрует сама (сначала предупреждает голосом, колёса немного крутятся), не чаще 2 раз за 10 минут. Отключить: `AISANA_LEGS_KEEPALIVE=0` или только автокалибровку: `AISANA_LEGS_AUTO_CALIBRATE=0`. Кнопка «🛞 Колёса» на пульте запускает `./legs_ready.sh` вручную.

### Калибровка колёс

После включения ODrive колёса надо откалибровать, и они при этом крутятся. Поэтому робот должен быть поднят, а сама Айсана никогда не калибрует (ни голосом, ни сама):

```bash
./calibrate_legs.sh    # спросит «колёса подняты? yes», запустит калибровку и дождётся результата
./calibrate_legs.sh --yes   # без вопроса (3 с предупреждение); так же делает ./start.sh сам
```

## Два режима

| | `aisana_realtime.py` — **быстрый, рекомендуемый** | `robot.py` — классический |
|---|---|---|
| Как работает | Звук идёт в OpenAI Realtime и обратно потоком | Запись → распознавание → GPT → озвучка |
| Задержка | Низкая: ответ звучит потоком, отдельных запросов STT/GPT/TTS нет | До шести запросов к OpenAI подряд на реплику |
| Имя «Айсана» | Нужно, чтобы начать разговор; дальше 20 с без имени | Нужно, чтобы начать разговор; дальше 35 с без имени |
| Камера, руки, погода, поиск | Модель сама вызывает инструменты | Команды рукам разбираются локально, остальное через маршрутизацию |
| Память диалогов SQLite | Пока нет | Есть |

## Запуск на Jetson

Быстрый режим работает в `.venv` (там websocket-client), классический — в системном `python3` (там cv2 из JetPack). У системного `python3` на Jetson нет pip.

```bash
cd ~/ai_robot
git pull --ff-only origin main
# один раз:
.venv/bin/python -m pip install "pyserial==3.5" "websocket-client==1.3.1"
sudo apt install python3-serial                       # pyserial для robot.py
sudo usermod -aG dialout $USER                        # доступ к Arduino; затем выйти из SSH и зайти снова
# каждый раз:
.venv/bin/python -m unittest discover -s tests -v     # офлайн-тесты, без железа
.venv/bin/python -u aisana_realtime.py 2>&1 | tee realtime.log   # быстрый режим
# или
python3 -u robot.py 2>&1 | tee robot.log              # классический режим
```

`OPENAI_API_KEY` должен быть в окружении. Флаг `-u` нужен, чтобы лог сразу писался в файл. Камеру realtime-режим снимает через `/usr/bin/python3 camera.py`, поэтому cv2 в `.venv` не нужен.

## Руки Arm team (Arduino Mega по USB)

Подключите USB-кабель Arduino Mega к Jetson. Прошивку Arm team (`robotic_arms_*.ino`, проверено с `robotic_arms_checked5.ino` от 23 ноября) **менять не нужно**: Айсана отправляет ей те же текстовые команды, что и Serial Monitor (115200 бод, перевод строки).

- Порт находится сам (обычно `/dev/ttyACM0`). Если плат несколько, Айсана откажется угадывать: задайте `AISANA_ARM_PORT=/dev/ttyACM0`.
- Без Arduino робот работает как обычно и пишет `Arm: not connected`.
- Отправляются **только** команды из белого списка: позиции 0–4 (вся рука, плечо или локоть), открыть/закрыть левый захват, помахать правой рукой, стоп (`x`), статус (`p`). Произвольный текст на Arduino не попадает никогда.
- **«Айсана, стоп»** в обоих режимах сразу отправляет аварийную остановку `x`.

### Что можно сказать Айсане

Разговор начинается с имени: «Айсана, …». После её ответа 12 секунд можно говорить без имени. Разговоры людей между собой в это время она старается пропускать молча.

| Что сказать | Что произойдёт |
|---|---|
| «Айсана, руки в позицию 2», «правую руку во вторую позицию», «левая рука, позиция четыре» | Рука (плечо и локоть) едет в сохранённую позицию 0–4 |
| «Айсана, правое плечо в позицию 1», «левый локоть в позицию 3» | Только этот сустав в позицию |
| «Айсана, руки в исходное положение», «руки в ноль» | Позиция 0 |
| «Айсана, рука чуть-чуть наверх» | Плечо выше на 5° |
| «подними правую руку немного», «левую руку немного ниже» | На 10° |
| «подними левую руку», «опусти руки» | На 15° |
| «подними руку сильно» | На 30° |
| «правую руку выше на 20 градусов» | На столько градусов, максимум 45 за раз |
| «левый локоть чуть выше», «опусти правый локоть немного» | То же, но локтем |
| «ещё», «ещё чуть-чуть» (только в быстром режиме) | Повторить последнее движение |
| «Айсана, открой левую руку», «открой захват» | Открыть захват (он только на левой руке) |
| «Айсана, закрой левую руку», «сожми захват», «возьми» | Закрыть захват |
| «Айсана, танцуй», «потанцуй 8 секунд», «dance» | Обе руки вверх (плечи в 3), правая кисть машет, она кружится с криками 8 с (максимум 10), потом руки вниз. `AISANA_DANCE_SECONDS=8` |
| «Айсана, помаши рукой», «пожми руку», «дай пять» | Правая рука поднимается (плечо 3, локоть 4) и кисть машет, 6 секунд (или «помаши 10 секунд»), потом рука опускается; раньше — «хватит махать» или «стоп». `AISANA_WAVE_SECONDS=6`, `AISANA_WAVE_POSE="3,4"` |
| **«Айсана, стоп»**, «останови руки» | Аварийная остановка всего (`x`) |
| «Айсана, где сейчас руки?», «статус рук» (быстрый режим) | Позиции суставов |
| «Aisana, move the left arm to position 3», «right arm a bit higher», «close both grippers», «stop the arms» | То же по-английски (казахский и арабский тоже понимает) |

Можно говорить несколько команд подряд: «правая рука позиция один, левая рука позиция два», «правое плечо в позицию 1. Позиция 4» (вторая команда относится к тому же плечу). Выполняются по порядку, последняя для сустава побеждает. Явные команды Айсана разбирает по точным словам человека, а не по догадке модели. После движения она читает датчики (потенциометры) и говорит правду: «доехала», «ещё едет» или «не сдвинулась».

«Наверх» — это в сторону позиции 4, как кнопка «forward» у Arm team. Если руки поедут не туда, запускайте с `AISANA_ARM_UP=position0`. Выход за пределы суставов прошивка не допускает: рука остановится на ближайшем пределе.

Характер: сухой сарказм в духе TARS из «Интерстеллара», уровень юмора по умолчанию 45%, меняется голосом: «Айсана, юмор 60 процентов». На «кто перед тобой?» она смотрит сразу и отвечает от первого лица («Передо мной какой-то красавчик…»), без «секунду, посмотрю». Шутки без оскорблений внешности.

### Гости по фото (с их согласия)

Для презентации можно заранее добавить людей по фото с должностью. Айсана здоровается с ними уважительно («Hello, Waqar Ahmad, President of Nazarbayev University. Welcome!») а юмор и сарказм остаются как обычно. Если нужно, чтобы при гостях она не шутила: `AISANA_VIP_MINUTES=15 ./start.sh`. Фото кладите в `faces_photos/` на Джетсоне (в GitHub не попадает):

```bash
.venv/bin/python enroll_face.py "Waqar Ahmad" "President of Nazarbayev University" faces_photos/waqar.jpg
.venv/bin/python enroll_face.py --list
.venv/bin/python enroll_face.py --forget "Waqar Ahmad"
```

### Язык

Сейчас Айсана говорит только по-английски (`AISANA_LANGUAGE=English`, понимает и русскую речь). Вернуть ответ на языке собеседника: `AISANA_LANGUAGE=auto ./start.sh`, другой язык: `AISANA_LANGUAGE=Russian`.

### Память о разговорах (realtime-режим)

Айсана помнит последние разговоры (общая память с `robot.py`, `~/.local/share/aisana/dialogue.sqlite3`): при запуске она получает 12 последних вопросов и ответов и может ответить «что мы вчера обсуждали». «Айсана, забудь наши разговоры» всё стирает. `AISANA_HISTORY_TURNS` — сколько помнить, `AISANA_MEMORY_ENABLED=0` — выключить.

### Имя «Айсана» распознаётся на Джетсоне (по желанию)

С `AISANA_LOCAL_WAKE=1` микрофон вне разговора слушает только Vosk на самом Джетсоне; в облако звук уходит после «Айсана» (и дальше, пока идёт разговор, едут колёса или она отвечает). Чужие разговоры не отправляются в OpenAI и не отвлекают её. Установка один раз:

```bash
cd ~/ai_robot
.venv/bin/python -m pip install "vosk==0.3.45"
mkdir -p models && cd models
wget -c https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip && unzip -n vosk-model-small-ru-0.22.zip
```

На JetPack 4 (Ubuntu 18.04) Vosk может не запуститься с ошибкой `undefined symbol: _ZNSt7__cxx1119basic_ostringstream...`: всем его сборкам для ARM64 нужен более новый `libstdc++`. Это меняет системную библиотеку, делайте осознанно: `sudo add-apt-repository ppa:ubuntu-toolchain-r/test && sudo apt update && sudo apt install --only-upgrade libstdc++6`. Без этого Айсана просто работает как раньше (имя распознаёт облако).

Если она стала плохо откликаться на имя, `AISANA_LOCAL_WAKE_CONFIDENCE=0.85` (мягче) или просто запускать без `AISANA_LOCAL_WAKE`.

### Лица и вещи (realtime-режим)

Камера включена всё время, поэтому вопросы про то, что перед ней, отвечаются быстрее. Лица распознаются прямо на Джетсоне (OpenCV dnn: YuNet находит лицо и 5 точек, лицо выравнивается, SFace превращает его в 128 чисел). YuNet лежит в `face_models/` (переделан под OpenCV 4.1.1, см. `tools/convert_yunet.py`), SFace скачивается в `models/` при первом запуске (около 39 МБ). Фото людей не сохраняются, только числа и имя, в `~/.local/share/aisana/faces_sface.sqlite3`. Пока человек говорит, она уже смотрит в камеру, поэтому «кто перед тобой?» отвечается быстрее (`AISANA_CAMERA_PREFETCH=0` выключает). Незнакомые лица не сохраняются никогда.

| Фраза | Что делает |
|---|---|
| «Айсана, запомни меня, я Али» | запоминает лицо (2 секунды смотри в камеру) |
| «Айсана, запомни его, это Нурлан» | запоминает лицо человека в кадре |
| «Айсана, кто перед тобой?» / «ты меня знаешь?» | называет знакомых по имени |
| «Айсана, забудь меня» / «забудь Нурлана» | удаляет лицо |
| «Айсана, кого ты знаешь?» | список людей и вещей |
| «Айсана, запомни, это моя кружка» | запоминает вещь и чья она |
| «Айсана, забудь кружку» | удаляет вещь |

Знакомого человека она сама приветствует, когда он появляется в кадре (не чаще раза в 30 минут). Настройки: `AISANA_FACES=0` выключает всё; `AISANA_FACE_GREET=0` отключает приветствия; `AISANA_FACE_GREET_MINUTES`; `AISANA_FACE_THRESHOLD` (1.0; меньше — строже). Запоминайте людей только с их согласия.

Без рук Айсана тоже умеет: «что ты видишь?», «прочитай, что здесь написано», «какая погода в Астане / завтра?», «кто победил на выборах?» (поиск в интернете), обычные вопросы. «Айсана, отбой» закрывает разговор; после этого снова нужно имя.

Важно для Arm team:
- При открытии USB-порта Arduino Mega перезагружается — это ожидаемо. Прошивка рассчитана на старт: локти стартуют из сохранённой калибровки, шаговики держат позицию. Айсана ждёт строку `Both arms ready.` и только потом шлёт команды. Моторное питание включайте **до** запуска Айсаны.
- Сервопривод левого локтя висит на пине 13 — это же светодиод платы, который загрузчик мигает при перезагрузке. Если локоть дёргается при запуске Айсаны, перенесите его на свободный пин (например, 11) и поменяйте `L_SERVO_PIN`.
- Пока Айсана держит порт, Serial Monitor в Arduino IDE этот порт открыть не сможет.

## Ноги (Raspberry Pi, колёса на ODrive)

Код на Raspberry Pi (`app.py` + `odrive_controller.py` команды ног) **менять не нужно**: Айсана пользуется тем же HTTP-API, что и страница `/control`. Jetson и Pi соединены LAN-кабелем.

1. На Pi запущен `python3 app.py` (порт 5000).
2. На Jetson один раз узнайте адрес Pi и проверьте связь: `curl http://<IP-Pi>:5000/motor/status`.
3. Запускайте Айсану с адресом Pi:
   ```bash
   AISANA_LEGS_URL=http://<IP-Pi>:5000 .venv/bin/python -u aisana_realtime.py 2>&1 | tee realtime.log
   ```

Безопасность:
- каждая поездка ограничена по времени: по умолчанию 2 с, «немного» 1 с, максимум 10 с. Айсана шлёт пульс только пока едет, и если Jetson, сеть или программа упадут, Pi сам остановится через 0,35 с;
- защиту Pi от препятствий (ближе 40 см) Айсана не обходит: при блокировке она говорит, что впереди препятствие;
- калибровку моторов голосом Айсана не запускает никогда. Если Pi просит калибровку, поднимите робота и нажмите CALIBRATE & ENABLE на странице `/control`;
- «Айсана, стоп» / «стой» сначала останавливает колёса, потом руки.

| Что сказать | Что произойдёт |
|---|---|
| «Айсана, вперёд!», «езжай вперёд», «назад» | Едет 2 с |
| «проедь вперёд 3 секунды», «на метр», «на 50 сантиметров», «отъедь назад немного» | По времени или расстоянию (до 10 с) |
| «повернись налево», «повернись направо на 45 градусов», «развернись», «развернись на 360» | Поворот на месте (90° по умолчанию, «развернись» — 180°) |
| «езжай налево / направо» | Едет по дуге |
| «покрутись 10 секунд», «покрутись 3 раза», «крутись налево два раза», «несколько раз» | Кружится на месте (максимум 10 с) |
| «…и кричи уииии» в любой команде | Выполняет и кричит |
| «быстрее», «медленнее» | Скорость ±0,5 км/ч (0,5–5,5) |
| «стоп», «стой» | Остановка |

Угол поворота считается по времени с учётом разгона ODrive: 90° ≈ `AISANA_LEGS_SPIN_90_SECONDS` (по умолчанию 0,84 с; с 23 ноября повороты в 1,4 раза длиннее), 360° — вдвое больше. Подберите это значение на полу.

Пока колёса крутятся, Айсана кричит свои выкрики («Уииии!», «Вжууух!»…). Она сама придумывает и записывает их без звука при запуске. Лишних слов при этом нет, а «стоп» работает прямо во время крика. Готовая фраза звучит только при настоящем препятствии: «Стоп! Препятствие в 29 сантиметрах.». «Повтори», «ещё раз», «повтори 10 раз» повторяют последнее движение.

| `AISANA_REALTIME_SILENCE_MS` | `700` | Realtime: сколько мс тишины считать концом фразы (больше — реже перебивает, но медленнее) |

| `AISANA_REALTIME_WAKE` | `1` | Realtime: `0` — отвечать на любую речь (старое поведение) |

## Файлы

- `aisana_realtime.py` — быстрый режим: Realtime API, имя, инструменты.
- `robot.py` — классический режим.
- `aisana_legs.py` — связь с ногами на Raspberry Pi по сети, разбор голосовых команд езды.
- `aisana_arm.py` — USB-связь с Arduino рук: поиск порта, белый список команд, разбор голосовых команд.
- `sadam_features.py` — погода (Open-Meteo), веб-поиск, определение конца фразы.
- `aisana_memory.py` — память диалогов (SQLite).
- `wake_listener.py` — офлайн-активация по имени (Vosk).
- `camera.py` — один кадр с камеры в `photo.jpg`.
- `speech.py`, `tts.py`, `vision.py` — старые тестовые скрипты первых версий.

## Разработка

Код должен работать на **Python 3.6** (Jetson Nano). CI на GitHub проверяет это (vermin) и гоняет офлайн-тесты на каждый push и pull request. Пока тесты красные, на Jetson не обновляйтесь.
