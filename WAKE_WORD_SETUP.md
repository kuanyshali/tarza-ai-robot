# Локальная активация Садама (Vosk) на Jetson Nano

Это **опциональный режим**. По умолчанию сохраняется старая, проверенная логика
`SADAM_WAKE_MODE=legacy`. Не включай локальный режим, пока не установил модель.

## Установка на Jetson

Внутри `~/ai_robot`:

```bash
python3 --version
uname -m
python3 -m pip --version
python3 -m pip install --user "vosk==0.3.45"
mkdir -p models
wget -c https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip -n vosk-model-small-ru-0.22.zip -d models/
python3 -c "from vosk import Model; print('Vosk installed')"
```

На Jetson Nano нужен ARM64 (`aarch64`). Vosk предоставляет соответствующий
wheel. Если `pip install` не сработает, пришли ошибку и версии Python/pip;
не стоит менять системный Python Jetson без необходимости.

Русская модель — примерно 45 МБ для скачивания и ~300 МБ в рабочей памяти.
Файлы под `models/` не попадают в Git.

## Включить режим Алисы

```bash
cd ~/ai_robot
SADAM_WAKE_MODE=vosk python3 robot.py
```

Ожидаемые сообщения:

```text
Wake mode: offline Vosk at models/vosk-model-small-ru-0.22
Wake listener: offline, waiting for "Sadam"...
Wake listener: recognized name locally.
Wake listener: phrase saved for multilingual transcription.
```

Попробуй сказать `Саддам, какая погода в Астане?` одной фразой, затем
`Садам` отдельно. После распознавания имени и конца фразы робот подаст
короткий сигнал на Xiaomi и передаст записанную фразу в облачную транскрипцию.

Пока робот ждёт имя, обычная речь фильтруется **локально** и не отправляется
в OpenAI; после активации действует прежний 20-секундный диалог без имени.
Камера, API-поиск и все голосовые ответы работают как раньше.

**Ограничения:**
- Локальное распознавание основано на **русской** Vosk-модели. Она может плохо
  узнавать латинское `Sadam`, арабское `صدام` и некоторые акценты.
  После активации облачное распознавание продолжает поддерживать русский,
  английский, казахский и арабский.
- Vosk распознаёт не отдельную акустическую команду с гарантированной точностью,
  а последовательность слов. На фоне громкой речи возможны ложные срабатывания;
  на тихом или необычном произношении — пропуски.
- Пробуждение прозвучит **после окончания произнесённой фразы**. Мгновенный
  сигнал на самом имени в середине длинной фразы потребует отдельной настройки
  акустического детектора/аппаратного эхоподавления.
- При неверной локальной активации облачное распознавание всё равно должно
  подтвердить произнесённое имя перед ответом.
- Не устанавливай крупные модели на Nano без проверки объёма RAM.

## Если распознавание имени не работает

Пока что достаточно вернуться в надёжный старый режим:

```bash
SADAM_WAKE_MODE=legacy python3 robot.py
```

Если локальный детектор узнаёт `Садам` неустойчиво, подбирай модель/настройку
акустики уже по реальным логам, а не повышай чувствительность без проверки.
